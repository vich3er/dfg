## 01_rollup_division_department

**Бізнес-питання:** Яка частка негативних згадок на рівні підрозділів і відділень (з проміжними підсумками та загальним підсумком)?

**Конструкція:** ROLLUP

```sql
-- question: Яка частка негативних згадок на рівні підрозділів і відділень (з проміжними підсумками та загальним підсумком)?
-- construct: ROLLUP
SELECT
    d.division_name,
    d.department_name,
    GROUPING(d.division_name, d.department_name) AS grouping_level,
    COUNT(*) AS mentions,
    ROUND(100.0 * SUM(f.is_negative) / COUNT(*), 1) AS negative_pct,
    ROUND(AVG(f.sentiment_score), 3) AS avg_sentiment
FROM fact_feedback_mention f
JOIN dim_department d ON d.department_key = f.department_key
GROUP BY ROLLUP (d.division_name, d.department_name)
ORDER BY d.division_name NULLS LAST, d.department_name NULLS LAST;
```

## 02_cube_class_channel

**Бізнес-питання:** Як розподіляються згадки та частка негативу за класами таксономії і каналами збору (усі комбінації підсумків)?

**Конструкція:** CUBE

```sql
-- question: Як розподіляються згадки та частка негативу за класами таксономії і каналами збору (усі комбінації підсумків)?
-- construct: CUBE
SELECT
    t.class_label,
    c.channel_name,
    GROUPING(t.class_label, c.channel_name) AS grouping_level,
    COUNT(*) AS mentions,
    ROUND(100.0 * SUM(f.is_negative) / COUNT(*), 1) AS negative_pct
FROM fact_feedback_mention f
JOIN dim_topic t   ON t.topic_key = f.topic_key
JOIN dim_channel c ON c.channel_key = f.channel_key
GROUP BY CUBE (t.class_label, c.channel_name)
ORDER BY grouping_level, t.class_label, c.channel_name;
```

## 06_pivot_class_quarter

**Бізнес-питання:** Як змінюється частка негативу (%) по класах тем від кварталу до кварталу?

**Конструкція:** PIVOT

```sql
-- question: Як змінюється частка негативу (%) по класах тем від кварталу до кварталу?
-- construct: PIVOT
SELECT * FROM (
    PIVOT (
        SELECT t.class_label, dd.quarter_label, f.is_negative AS neg
        FROM fact_feedback_mention f
        JOIN dim_topic t ON t.topic_key = f.topic_key
        JOIN dim_date dd ON dd.date_key = f.date_key
    )
    ON quarter_label
    USING ROUND(100.0 * AVG(neg), 1)
    GROUP BY class_label
)
ORDER BY class_label;
```

## 07_window_cumulative_critical

**Бізнес-питання:** Як накопичуються критичні згадки (безпека пацієнта) з місяця в місяць?

**Конструкція:** ВІКОННА ФУНКЦІЯ (накопичувальна сума)

```sql
-- question: Як накопичуються критичні згадки (безпека пацієнта) з місяця в місяць?
-- construct: ВІКОННА ФУНКЦІЯ (накопичувальна сума)
WITH m AS (
    SELECT dd.month_label, SUM(f.is_critical) AS critical_mentions, COUNT(*) AS mentions
    FROM fact_feedback_mention f
    JOIN dim_date dd ON dd.date_key = f.date_key
    GROUP BY dd.month_label
)
SELECT
    month_label,
    critical_mentions,
    SUM(critical_mentions) OVER (ORDER BY month_label) AS cumulative_critical,
    ROUND(100.0 * critical_mentions / mentions, 2) AS critical_pct
FROM m
ORDER BY month_label;
```

## 08_window_rank_subclass

**Бізнес-питання:** Які підкласи тем найпроблемніші всередині свого класу та загалом (ранг за часткою негативу)?

**Конструкція:** ВІКОННА ФУНКЦІЯ (RANK, PARTITION BY)

```sql
-- question: Які підкласи тем найпроблемніші всередині свого класу та загалом (ранг за часткою негативу)?
-- construct: ВІКОННА ФУНКЦІЯ (RANK, PARTITION BY)
WITH s AS (
    SELECT t.class_label, t.topic_label, COUNT(*) AS mentions,
           ROUND(100.0 * SUM(f.is_negative) / COUNT(*), 1) AS negative_pct
    FROM fact_feedback_mention f
    JOIN dim_topic t ON t.topic_key = f.topic_key
    GROUP BY t.class_label, t.topic_label
    HAVING COUNT(*) >= 30
)
SELECT
    class_label, topic_label, mentions, negative_pct,
    RANK() OVER (PARTITION BY class_label ORDER BY negative_pct DESC) AS rank_in_class,
    RANK() OVER (ORDER BY negative_pct DESC) AS rank_overall
FROM s
ORDER BY rank_overall;
```

## 09_window_moving_avg_waiting

**Бізнес-питання:** Яка динаміка тональності за темами очікування (ковзне середнє за 3 місяці)?

**Конструкція:** ВІКОННА ФУНКЦІЯ (ковзне середнє, ROWS BETWEEN)

```sql
-- question: Яка динаміка тональності за темами очікування (ковзне середнє за 3 місяці)?
-- construct: ВІКОННА ФУНКЦІЯ (ковзне середнє, ROWS BETWEEN)
WITH m AS (
    SELECT dd.month_label, ROUND(AVG(f.sentiment_score), 3) AS avg_sentiment, COUNT(*) AS mentions
    FROM fact_feedback_mention f
    JOIN dim_topic t ON t.topic_key = f.topic_key
    JOIN dim_date dd ON dd.date_key = f.date_key
    WHERE t.class_code = 'WaitingOrganization'
    GROUP BY dd.month_label
)
SELECT
    month_label, mentions, avg_sentiment,
    ROUND(AVG(avg_sentiment) OVER (ORDER BY month_label ROWS BETWEEN 2 PRECEDING AND CURRENT ROW), 3) AS moving_avg_3m
FROM m
ORDER BY month_label;
```

```sql
-- question: DRILL-DOWN, рівень 2 (підклас): які підкласи «найгіршого» класу дають найбільше негативу?
-- construct: DRILL-DOWN по ієрархії таксономії (клас -> підклас)
WITH worst AS (

    FROM fact_feedback_mention f
    JOIN dim_topic t ON t.topic_key = f.topic_key
    GROUP BY t.class_iri
    ORDER BY SUM(f.is_negative) * 1.0 / COUNT(*) DESC
    LIMIT 1

SELECT
    t.class_label,
    t.topic_iri,
```

## 11_cooccurrence_semantic_network

**Бізнес-питання:** Які теми найчастіше згадуються разом в одному відгуку (ребра семантичної мережі) і наскільки це вище за випадкове (lift)?

**Конструкція:** SELF-JOIN факту по відгуку + lift (основа для fb:coOccursWith)

```sql
-- question: Які теми найчастіше згадуються разом в одному відгуку (ребра семантичної мережі) і наскільки це вище за випадкове (lift)?
-- construct: SELF-JOIN факту по відгуку + lift (основа для fb:coOccursWith)
WITH n AS (SELECT COUNT(DISTINCT feedback_id) AS N FROM fact_feedback_mention),
tc AS (SELECT topic_key, COUNT(DISTINCT feedback_id) AS c FROM fact_feedback_mention GROUP BY 1),
p AS (
    SELECT a.topic_key AS ta, b.topic_key AS tb, COUNT(*) AS together
    FROM fact_feedback_mention a
    JOIN fact_feedback_mention b ON a.feedback_id = b.feedback_id AND a.topic_key < b.topic_key
    GROUP BY 1, 2
)
SELECT
    da.topic_label AS topic_a,
    db.topic_label AS topic_b,
    p.together,
    ROUND((p.together * 1.0 * n.N) / (ca.c * cb.c), 2) AS lift
FROM p CROSS JOIN n
JOIN tc ca ON ca.topic_key = p.ta
JOIN tc cb ON cb.topic_key = p.tb
JOIN dim_topic da ON da.topic_key = p.ta
JOIN dim_topic db ON db.topic_key = p.tb
WHERE p.together >= 15
ORDER BY lift DESC
LIMIT 10;
```

## 12_scd2_risk_group

**Бізнес-питання:** Чи відрізняється тональність відгуків пацієнтів різних груп ризику (група береться на дату відгуку — SCD тип 2)?

```sql
-- question: Чи відрізняється тональність відгуків пацієнтів різних груп ризику (група береться на дату відгуку — SCD тип 2)?
-- construct: JOIN до SCD2-виміру
SELECT
    p.risk_group,
    COUNT(*) AS mentions,

GROUP BY p.risk_group
ORDER BY CASE p.risk_group WHEN 'низький' THEN 1 WHEN 'середній' THEN 2 ELSE 3 END;
```
