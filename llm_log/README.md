# Журнал взаємодії з LLM (протокол «LLM-експерт»)

Для **кожної** взаємодії з LLM додайте запис (файл `llm_log/YYYY-MM-DD_<тема>.json` або рядок у `t2sql_calls.jsonl`):

| Поле | Що вказати |
|---|---|
| `date` | дата й час |
| `model` | точна модель і версія (напр. з інтерфейсу чи API) |
| `parameters` | temperature, seed, max_tokens (якщо недоступні — вказати «за замовчуванням інтерфейсу») |
| `prompt_version` | версія підказки (v1, v2…) |
| `prompt` | текст підказки |
| `raw_output` | сирий вихід моделі без редагування |
| `human_decision` | прийнято / змінено / відхилено + пояснення |

Виклики `AnthropicBackend` (`text2sql/backends.py`) журналюються автоматично у `llm_log/t2sql_calls.jsonl`; поле `human_decision` заповніть вручну.

**Важливо:** файл `2026-11-19_project_scaffold.json` — чернетка-заготовка з описом того, як було отримано початкові файли проєкту. Заповніть поля, позначені `<…>`, власними **достовірними** даними (модель, версія, ваші підказки) і задокументуйте, що саме ви перевірили та змінили. Не вказуйте того, чого не було.
